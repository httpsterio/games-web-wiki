# Games wiki

Plans, future work and history for the games collection. The code lives in httpsterio/games-web.

What goes where:

- Rules the code must follow live in games-web docs (docs/decisions.md and each game's docs).
- This wiki holds the roadmap, future plans, infra ideas and how things used to be.

Open questions are marked **Open**.

- [App settings and save file](app-settings-and-save-file.md): one settings page and one save file for all games.
- [Decided rules](decided-rules.md): rules agreed for all games, as recorded in planning.
- [Flowdoku](flowdoku.md): hint wording, technique pages, small open items.
